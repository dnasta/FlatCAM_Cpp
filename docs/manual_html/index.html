FlatCAM C++

Port nativo de FlatCAM 2024.4 para fabricar placas de circuito impreso: importá Gerber y Excellon, generá aislamiento, taladrado, corte, NCC y pintura, previsualizá el resultado y exportá G-code para tu CNC.

¿Qué podés hacer con FlatCAM C++?

El flujo completo, desde los archivos de tu CAD hasta el G-code que entiende tu máquina.

📥

Importar

Gerber RS-274X, Excellon, G-code, SVG, DXF, HPGL2, PDF vectorial e imágenes.
⭕

Aislar cobre

Una o varias pasadas, solape, V-shape, follow, combine y rest machining.
🕳

Perforar

Taladros y ranuras desde Excellon, con peck, offsets y orden optimizado.
✂

Cortar contorno

Separá la placa con margen, puentes, multipasada y agujeros internos.
▦

NCC y pintura

Remoción de cobre no conectado y relleno de áreas con hatch o contornos.
🧰

Herramientas

Film, panelizado, thieving, solder paste, QR, imagen, punch y calibración.
✎

Editar

Editores Gerber, Excellon y geometría; booleanas, transformaciones y undo.
⌨

Automatizar

71 comandos Tcl, API JavaScript y CLI para repetir el trabajo sin clics.

Inicio rápido

  1. Abrí un Gerber y un Excellon. Arrastrá los archivos a la ventana o usá Archivo → Abrir. Cada archivo queda como un objeto del proyecto.
  2. Elegí la herramienta. Para una placa simple: Herramienta → Aislamiento con una fresa de 0,2 mm y una pasada; después Perforación con la tabla del Excellon; por último Corte con el contorno.
  3. Previsualizá. Revisá los recorridos en el canvas y la tabla de herramientas. Ajustá diámetro, solape, profundidad y avances antes de generar.
  4. Generá el CNCJob y exportá G-code. El programa se agrega al grupo G-code del proyecto y se puede abrir en el editor o guardar como .nc.

Antes de mecanizar: hacé una simulación en vacío, verificá la altura Z, el cero de la pieza y que el diámetro de la fresa coincida con el de la tabla. Un error de 0,1 mm puede arruinar la placa.

Estado de esta versión

FlatCAM C++ v0.2.1 consolida la documentación Doxygen, el manual del código y las correcciones de importadores y herramientas. Incluye las 33 herramientas del FlatCAM original con equivalentes funcionales, editores, importación/exportación ampliada y vista 3D. Está probada con una placa real de 5 capas y 120 taladros.

El binario publicado es para macOS 14.4 o superior en Apple Silicon. En Windows y Linux el código compila con Qt 6 y GEOS, pero todavía no hay instaladores oficiales.
