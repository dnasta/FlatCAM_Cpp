Instalación

macOS, compilación y primeros pasos

FlatCAM C++ se distribuye como una aplicación macOS autocontenida. También se puede compilar desde el código fuente en macOS, Linux y Windows.

Requisitos

ElementoMínimoRecomendado
SistemamacOS 14.4 (Sonoma)macOS 15 o superior
ArquitecturaApple Silicon (arm64)Apple Silicon
RAM4 GB8 GB o más
Disco200 MB500 MB
Pantalla1200 × 8001440 × 900 o más

Instalar desde el DMG

  1. Descargá FlatCAM-CPP-0.1.0-arm64.dmg desde Releases.
  2. Hacé doble clic para montar la imagen.
  3. Arrastrá FlatCAM C++ a la carpeta Aplicaciones.
  4. La primera vez, hacé clic derecho sobre la app y elegí Abrir. La firma es ad-hoc; macOS muestra una advertencia de desarrollador no verificado.
  5. Confirmá Abrir en el diálogo de seguridad.

Si macOS bloquea la app y no aparece la opción Abrir, andá a Ajustes del Sistema → Privacidad y seguridad y elegí Abrir igualmente. No es necesario desactivar Gatekeeper globalmente.

Qué incluye el bundle

  • Aplicación Qt 6 con iconos y temas.
  • Qt, GEOS, zlib y las licencias de terceros embebidas.
  • CLI y motor JavaScript: 
    "/Applications/FlatCAM C++.app/Contents/MacOS/flatcam-cli" --help
"/Applications/FlatCAM C++.app/Contents/MacOS/flatcam-js" script.js
  • Proyecto de ejemplo y archivos de muestra dentro de la app.

Primer arranque

Al abrir la app vas a ver el árbol de proyecto vacío, el canvas y la consola Tcl. Podés arrastrar un Gerber o usar Archivo → Abrir. Los archivos de ejemplo están en examples/ del repositorio.

Compilar desde el código fuente

Para desarrollar o para otras plataformas:

# Dependencias en macOS
brew install cmake geos googletest
# Qt 6.4+ (instalador oficial o brew install qt)

cmake -S . -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH="$HOME/Qt/6.12.0/macos"
cmake --build build -j8
./build/flatcam_tests
./build/flatcam-gui.app/Contents/MacOS/flatcam-gui

Empaquetar en macOS

./tools/create_dmg.sh 0.1.0
# Genera dist/FlatCAM-CPP-0.1.0-arm64.dmg

El script compila, ejecuta macdeployqt, copia GEOS, incrusta licencias, firma ad-hoc y crea el DMG con la app renombrada a FlatCAM C++.app.

Windows y Linux

El código es portable y CMake detecta GEOS por pkg-config o por configuración. Todavía no hay instaladores oficiales. En Linux hacen falta libgeos-dev, zlib1g-dev, Qt 6 y Tcl; en Windows, vcpkg o binarios precompilados de GEOS y Qt MSVC.

Desinstalar

Arrastrá la app a la papelera. Las preferencias quedan en ~/Library/Preferences y la base de datos de herramientas en ~/Library/Application Support; se pueden borrar manualmente si querés empezar de cero.

Los archivos de proyecto .FlatPrj son independientes de la instalación. Guardalos junto a tus Gerber para no perder las tablas de herramientas.
