Automatización

Consola Tcl, JavaScript y CLI

FlatCAM C++ se puede manejar sin la GUI: consola Tcl integrada, API JavaScript y CLI. Ideal para repetir trabajos, generar lotes o integrar con scripts.

Consola Tcl

La pestaña Shell Tcl del panel inferior es un intérprete Tcl real. Escribí un comando y Enter. También se puede ejecutar un script con source archivo.tcl o desde la CLI.

open_gerber examples/board_copper.gbr
isolate 0.2 1 0.1
export_gcode /tmp/aislamiento.nc

API JavaScript

La pestaña Consola JS y el ejecutable flatcam-js usan QJSEngine. La API vive en el objeto flatcam:

flatcam.openGerber("examples/board_copper.gbr");
flatcam.isolate(0.2, 1, 0.1);
flatcam.exportGcode("/tmp/iso.nc");
flatcam.log(flatcam.info());
FunciónUso
openGerber(path)Abre un Gerber.
openExcellon(path)Abre un Excellon.
isolate(dia, passes, overlap)Aislamiento.

CLI

flatcam-cli gerber archivo.gbr --json
flatcam-cli isolate archivo.gbr --tool-dia 0.2 --passes 2 --overlap 10 -o iso.nc
flatcam-cli cutout contorno.gbr --tool-dia 1.5 --margin 0.5 --tabs 4 -o cut.nc
flatcam-cli ncc cobre.gbr --tool-dia 0.5 --superposition 80 -o ncc.nc
flatcam-cli gcode taladros.drl --preprocessor grbl --optimize -o drill.nc
flatcam-cli project proyecto.FlatPrj --info
flatcam-cli tcl

La CLI incluida en el bundle está en FlatCAM C++.app/Contents/MacOS/flatcam-cli.

Scripts de proyecto

Un objeto Script guarda código JavaScript y se ejecuta desde el editor. Es útil para dejar dentro del proyecto el proceso completo de generación.

flatcam.openGerber("board_copper.gbr");
flatcam.isolate(0.2, 2, 15);
flatcam.exportGcode("board_iso.nc");

Para automatizar un lote, abrí el proyecto, recorré los objetos con get_names, aplicá la herramienta y exportá con nombres derivados. Guardá siempre el proyecto antes de sobrescribir G-code.
