Descripción detallada

Punto de entrada de flatcam-cli: despacho de subcomandos CAM.

La CLI interpreta un primer argumento (gerber, excellon, gcode, isolate, cutout, ncc, paint, mill, svg, dxf, film, import-svg, import-dxf, thieving, project, tcl) y ejecuta el parser o la herramienta correspondiente. Las opciones se comparten entre comandos mediante una única estructura Args y cada ejecución termina en una función runXxx que imprime estadísticas en texto o JSON o escribe el archivo de salida pedido.

Punto de entrada: interpreta los argumentos y despacha el subcomando.

Envuelve parseArgs y el despacho en un try/catch que convierte cualquier excepción de la biblioteca estándar o del parser en un mensaje error: ... con código de salida 1.

Parámetros
argcCantidad de argumentos.
argvVector de argumentos.
Devuelve
0 en éxito; 1 si una excepción interrumpe la ejecución; 2 si la línea de comandos es inválida o el subcomando es desconocido.
Nota
El subcomando tcl se delega en fc::runTclScript, cuya implementación depende de si el build encontró libtcl.
Cada runXxx recibe la estructura completa de opciones; no hay validación cruzada entre el subcomando y las banderas, de modo que opciones irrelevantes se aceptan y se ignoran.
