Descripción detallada

Handler SAX que entrega cada objeto al visitante y lo libera.

Es el modo de carga secuencial: mantiene un solo objeto en memoria, calcula un resumen (clase, nombre, unidades, cantidad de geometrías, área y caja) y llama al visitante; si éste devuelve false se aborta el parseo.

bool fc::AllObjectsSax::finishObject ( )
inline

Completa y entrega el objeto recién leído.

Rellena clase y nombre faltantes, mueve las geometrías acumuladas, calcula el resumen (suma de áreas y unión de cajas de los sólidos) y llama al visitante.

Devuelve
false si el visitante pidió detener el recorrido.
