Descripción detallada

Editor modal de G-code con resaltado de sintaxis y guardado en sitio.

Implementa un QSyntaxHighlighter propio con reglas para G, M, T, ejes (X/Y/Z/I/J/K), avances/velocidad (F/S) y números, más los comentarios entre paréntesis, y un diálogo que carga el archivo completo en un QPlainTextEdit oscuro y permite guardarlo sobrescribiendo el original.

◆ openGCodeEditor()

void openGCodeEditor ( const QString & path,
QWidget * parent = nullptr )

Abre el editor de G-code para un archivo.

Lee el archivo como UTF-8 y crea un QDialog no modal con WA_DeleteOnClose (se libera al cerrarse), un QPlainTextEdit con fuente monoespaciada y fondo oscuro, el resaltador asociado y una caja con Guardar/Cerrar. El botón Guardar sobrescribe el archivo original con el contenido del editor, sin copia de seguridad, y marca el título con el sufijo "(guardado)".

Parámetros
pathArchivo a editar.
parentWidget padre del diálogo.
Nota
Si el archivo no se puede leer se muestra un aviso y no se abre nada. El texto se carga completo en memoria: archivos de cientos de MB pueden consumir mucha RAM.
Atención
No se pide confirmación al cerrar con cambios sin guardar y el botón Guardar no cierra el diálogo ni controla el estado modificado (GCodeEditor.cpp:150-162).
