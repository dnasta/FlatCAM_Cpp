◆ exportGcode()

bool fc::ScriptApi::exportGcode ( const QString & path)

Exporta el último CNCJob a G-code.

Exporta el trabajo activo a un archivo G-code.

Si hay DrillJob genera taladrado; si no, los recorridos de geometría. Usa GCodeOptions por defecto (milímetros, preprocesador Default).

Parámetros
pathArchivo de destino.
Devuelve
true si se escribió; false con lastError() si no hay trabajo, no se puede abrir el archivo o el generador lanza una excepción.
Nota
La escritura usa QIODevice::Text, de modo que en Windows el texto puede convertirse a CRLF (los firmwares suelen aceptarlo).
Atención
No hay parámetros de máquina expuestos: avances, Z, husillo y postprocesador no se pueden configurar desde el script.
QFile::write(code.c_str()) depende del terminador nulo y no pasa la longitud; es correcto para G-code sin bytes nulos, pero no es la forma recomendada de escribir datos binarios.

◆ panelize()

int fc::ScriptApi::panelize ( int rows,
int cols,
double gapX = 2.0,
double gapY = 2.0,
double angle = 0.0 )

Paneliza el objeto activo.

Paneliza el objeto activo rotándolo y repitiéndolo en una grilla.

Rota cada sólido angle grados alrededor del centro del bounding box original, calcula la caja del conjunto rotado y luego copia la pieza en rows × cols posiciones, separadas por ancho + gapX y alto + gapY, alineando la primera celda con el origen original. Entrega todas las copias al LayerSink con nombre panel.

Parámetros
rowsFilas de la grilla (≥ 1).
colsColumnas de la grilla (≥ 1).
gapXSeparación horizontal extra.
gapYSeparación vertical extra.
angleRotación en grados.
Devuelve
Cantidad de geometrías generadas, o -1 si falta el Gerber, las filas o columnas no son positivas, o la caja resultante no es válida.
Nota
rows < 1 o cols < 1 informan no gerber loaded, mensaje engañoso que no describe el problema real.
Sólo se panelizan los sólidos; los recorridos "follow" no se replican.
La función no modifica gerber_: el panel existe únicamente en la capa entregada al LayerSink.
