Descripción detallada

Modelo y persistencia de proyectos .FlatPrj.

Un proyecto FlatCAM es un JSON con version, options y objs. La geometría se guarda como WKT dentro de objetos {"__class__": "Shply"}. El archivo puede estar comprimido con lzma; la lectura usa streaming para proyectos de varios gigabytes.
