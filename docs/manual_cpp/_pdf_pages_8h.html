Renderiza todas las páginas de un PDF a imágenes.

Implementación vacía para plataformas sin PDFKit.

En macOS usa PDFKit. En otras plataformas devuelve un vector vacío.

Parámetros
pathArchivo PDF.
dpiResolución de render.
pageSizesMmSi no es nulo, recibe el tamaño de cada página en mm.
Devuelve
Imágenes en orden de página.

Renderiza todas las páginas de un PDF a imágenes.

Devuelve
Siempre un vector vacío, de modo que el llamador caiga al método alternativo de rasterizado (por ejemplo sips o un importador externo).
Nota
Mantiene la firma de PdfPages.h para que la GUI compile igual en Windows y Linux.
