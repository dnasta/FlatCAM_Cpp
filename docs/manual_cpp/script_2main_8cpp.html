Descripción detallada

Punto de entrada del ejecutable de scripting flatcam-js.

Ejecuta un archivo JavaScript con QJSEngine (Qt Core/Qml), sin GUI, tras instalar la API fc::ScriptApi como objeto global flatcam y la función print(). Es el equivalente de consola del scripting nativo del proyecto.

◆ main()

int main ( int argc,
char ** argv )

Carga y evalúa el script indicado en la línea de comandos.

Flujo: crea QCoreApplication, valida que haya un argumento, lee el archivo completo como UTF-8, crea el motor, instala la API y evalúa el código usando la ruta como nombre de archivo (para que los errores informen la ubicación).

Parámetros
argcDebe ser al menos 2 (programa + script).
argvRuta del script en argv[1].
Devuelve
0 si el script se evalúa sin error; 1 si el archivo no se puede abrir o la evaluación devuelve un error; 2 si faltan argumentos.
Nota
No llama a engine.installExtensions(ConsoleExtension): console.log no está disponible, pero print() sí, porque lo define installScriptApi.
Los errores de script se escriben por stderr y detienen el proceso; no se ejecuta ningún catch de JavaScript que el script no haya definido.
Atención
api se construye después de engine, de modo que se destruye antes. Como newQObject aplica JavaScriptOwnership, el motor podría intentar borrarlo en su destructor; ver la advertencia de installScriptApi.
