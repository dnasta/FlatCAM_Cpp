Descripción detallada

Núcleo geométrico inmutable sobre la API C de GEOS.

FlatCAM C++ usa GEOS para todas las operaciones 2D: uniones, diferencias, intersecciones, buffers, simplificación, reparación y transformaciones. Este archivo define los tipos básicos (Pt, Ring, BBox, PolygonContours) y dos envoltorios RAII:

  • fc::Geom: geometría inmutable con copia barata (puntero compartido).
  • fc::SpatialIndex: índice STRtree para consultas por caja envolvente.

GEOS no es reentrante en su API clásica; initGeosRuntime() se llama de forma automática desde las fábricas de Geom.
