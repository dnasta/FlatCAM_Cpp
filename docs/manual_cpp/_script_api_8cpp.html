Descripción detallada

Implementación de la API JavaScript (QJSEngine) de FlatCAM.

fc::ScriptApi es una fachada con métodos Q_INVOKABLE que reutiliza el núcleo CAM (parsers, aislamiento, corte, NCC, pintura, taladrado, utilidades de herramientas y QR) para exponerlos a scripts .js y a la consola integrada. Mantiene el último Gerber/Excellon y el trabajo activo, y puede entregar cada capa generada a la GUI mediante un LayerSink.
